One command, and it plays by the rules

You type it once, out of combat. Turbo writes the macros you would have written by hand and swaps them onto your bars. It never touches anything of yours.

/turbo macros

Also /tb macros

Use: Makes a character macro for each attack spell you know.

Use: Every macro starts auto-attack, then casts the spell.

Use: No rank in the macro, so the game always casts your top rank.

Use: Swaps each macro onto your bars wherever that spell sat, at any rank.

"Spell names come from the game, so it works in any language."

  • Only out of combat, with an empty cursor. In combat or holding something, it tells you and changes nothing.
  • Your macros stay yours. Turbo never edits or deletes a macro it didn't make.
  • No duplicates. Run it again any time; it finds its own macros and only adds what's missing.
  • All or nothing. If you don't have enough free character macro slots, it changes nothing and tells you how many it needs.

Set up in a minute

Nothing to configure. There are no settings and no window.

  1. Install

    Get Turbo from CurseForge.

  2. Log in

    Pick your character and enter the world.

  3. Type the command

    Out of combat, type /turbo macros.

  4. Done

    Your attack buttons are now macros, in the same slots.

Learned a new rank? Nothing to do. The macros have no rank in them, so they already cast your newest one.

Learned a new attack spell? Put it on your bars and run /turbo macros again. It skips everything that's already done.
